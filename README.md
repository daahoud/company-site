# Skyline Technologies 企業サイト

スカイライン・テクノロジーズの企業紹介サイトです。会社概要、サービス内容、導入実績、メンバー紹介、お問い合わせ情報を掲載した静的なランディングページ（`index.html`）で構成されています。

## 使い方

1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をダブルクリックするか、ブラウザに直接ドラッグ&ドロップして開きます。
3. または、ブラウザのアドレスバーに以下のようなパスを入力しても開けます。

   ```
   file:///path/to/company-site/index.html
   ```

サーバー環境は不要で、ブラウザだけで閲覧できます。
